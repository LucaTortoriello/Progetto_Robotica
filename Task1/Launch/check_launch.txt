CHECKLIST LAUNCH FILE - TASK 1 (REVISIONATA)

OBIETTIVO
=========
Avviare con il launch solo i nodi del Task 1:
1) nodo action server scansione testa (`det_task1`),
2) nodo detector ArUco (`aruco_detector_all_markers`).

NOTA AULA: Gazebo/TIAGo viene avviato in un terminale separato.


PERCORSI SORGENTE -> DESTINAZIONE (DA VERIFICARE)


Destinazioni nel workspace ROS2 (workspace reale: ~/progetto_12_ws):
- ~/progetto_12_ws/src/my_bringup/launch/launch_task1.py
- ~/progetto_12_ws/src/task1_pkg/task1_pkg/det_task1.py

STEP 1 - POSIZIONAMENTO FILE
============================
□ Verificare che esista la cartella launch del package:
  mkdir -p ~/progetto_12_ws/src/my_bringup/launch

□ Copiare il launch:
  cp "/home/ubuntu/Cinematica Diretta/Progetto_Robotica/Task1/Launch/launch_task1.py" \
  ~/progetto_12_ws/src/my_bringup/launch/

□ Copiare/aggiornare i nodi Python nel modulo package:
  cp "/home/ubuntu/Cinematica Diretta/Progetto_Robotica/Task1/nodi/det_task1.py" \
  ~/progetto_12_ws/src/task1_pkg/task1_pkg/

  cp "/home/ubuntu/Cinematica Diretta/Progetto_Robotica/Task1/nodi/aruco_detector_all_markers.py" \
      ~/progetto_12_ws/src/task1_pkg/task1_pkg/


STEP 2 - setup.py (ENTRY POINT)
===============================
□ In ~/progetto_12_ws/src/task1_pkg/setup.py verificare `console_scripts`:
  - 'det_task1 = task1_pkg.det_task1:main'
  - 'aruco_detector_all_markers = task1_pkg.aruco_detector_all_markers:main'


STEP 3 - BUILD E SOURCE CORRETTI
================================
□ Compilare:
  cd ~/progetto_12_ws
  source /opt/ros/humble/setup.bash
  colcon build --symlink-install

□ Sorgentare overlay:
  source ~/progetto_12_ws/install/setup.bash


STEP 4 - AVVIO LAUNCH UNICO
===========================
□ Terminale separato per Gazebo (prima del launch Task 1):
  ros2 launch tiago_gazebo tiago_gazebo.launch.py is_public_sim:=True

□ Avvio:
  ros2 launch my_bringup launch_task1.py

□ Atteso:
  - nodo `action_server_head_scan` attivo
  - nodo `aruco_detector` attivo
  - Gazebo resta in esecuzione nel terminale separato


STEP 5 - TEST RAPIDI
====================
□ Nodi attivi:
  ros2 node list

□ Goal scansione:
  ros2 action send_goal /move_head my_robot_interfaces/action/MoveHead "{min: -0.217, max: 0.217, step: 0.05}"

□ Topic ArUco:
  ros2 topic list | grep aruco


TROUBLESHOOTING MIRATO
======================
1) Gazebo/TIAGo non avviato:
  - non è più un errore del file `launch_task1.py`
  - avviare Gazebo manualmente nel terminale dedicato

2) `Could not find executable 'det_task1'`:
   - entry point mancanti in setup.py
   - rebuild e source mancanti

3) Nessun topic `/aruco_*`:
   - marker non visibili in camera
   - detector non in esecuzione o errori OpenCV/TF


NOTE FINALI
===========
- Il comando corretto è: `ros2 launch my_bringup launch_task1.py`
- Evitare dipendenza da `source ~/.bashrc` per i test: usare source esplicito ROS + workspace.
- In ROS2 non aspettarsi messaggi di tipo "ROS master" (tipici ROS1).
