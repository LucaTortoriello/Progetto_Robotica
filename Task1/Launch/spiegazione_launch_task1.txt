Spiegazione aggiornata di launch_task1.py

Il file launch_task1.py avvia in un solo comando i 3 componenti del Task 1:
1) simulazione TIAGo,
2) action server scansione testa,
3) detector ArUco multi-marker.


1) Importazioni principali
==========================
Import usati nel launch:
- get_package_share_directory e PackageNotFoundError
- IncludeLaunchDescription + PythonLaunchDescriptionSource
- Node

Servono per:
- trovare i package ROS2 nel filesystem,
- includere il launch TIAGo,
- avviare i due nodi Python del progetto.


2) Risoluzione robusta del launch TIAGo
=======================================
È stata aggiunta la funzione:
- _resolve_tiago_gazebo_launch_path()

Questa funzione prova in ordine:
1. package `tiago_gazebo`
2. package `tiago_gazebo_simulation`

e cerca `launch/tiago_gazebo.launch.py`.

Vantaggio: il file resta compatibile con setup diversi del laboratorio.
Se nessun package è disponibile, il launch alza un errore esplicito.


3) Include del launch TIAGo
===========================
L'include usa:
- PythonLaunchDescriptionSource(percorso_launch_tiago)
- parametro launch: `is_public_sim=True`

Questo mantiene il comportamento usato nelle esercitazioni TIAGo in simulazione pubblica.


4) Nodo scansione testa (Action Server)
=======================================
Nodo lanciato:
- package: `progetto_robotica`
- executable: `det_task1`
- name: `action_server_head_scan`

Richiede in setup.py l'entry point:
- 'det_task1 = progetto_robotica.det_task1:main'


5) Nodo detector ArUco
======================
Nodo lanciato:
- package: `progetto_robotica`
- executable: `aruco_detector_all_markers`
- name: `aruco_detector`

Richiede in setup.py l'entry point:
- 'aruco_detector_all_markers = progetto_robotica.aruco_detector_all_markers:main'


6) Ordine di avvio
==================
La LaunchDescription contiene:
1. include launch TIAGo Gazebo
2. `det_task1`
3. `aruco_detector_all_markers`


7) Percorsi corretti da usare nel deployment
============================================
Sorgenti (repo corrente):

- /home/ubuntu/Cinematica Diretta/Progetto_Robotica/Task1/nodi/det_task1.py

8) Comando finale
=================
Comando da usare:
- ros2 launch progetto_robotica launch_task1.py

Prerequisiti minimi:
- build del workspace (`colcon build --symlink-install`)
- source overlay (`source ~/progetto_n_ws/install/setup.bash`)
