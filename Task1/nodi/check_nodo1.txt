CHECKLIST PASSO PASSO - INTEGRAZIONE NODO 1 (SCAN TESTA)
Workspace target Ubuntu: ~/progetto_12_ws

Riferimenti esercitazioni usati:
- Esercitazioni/Esercitazione4-Action/codes/action_server.py
- action/ReadMe_Tiago
- Task1/det_task1.py

=====================================================================
FASE 0 - PREPARAZIONE AMBIENTE
=====================================================================
1) Apri terminale e prepara ambiente ROS 2:
source /opt/ros/humble/setup.bash
cd ~/progetto_12_ws/src

2) Verifica struttura workspace:
ls

=====================================================================
FASE 1 - CREAZIONE PACKAGE NECESSARI
=====================================================================
NOTA: det_task1.py usa una Action custom MoveHead, quindi servono 2 package:
- my_robot_interfaces (interfacce action)
- task1_pkg (nodo Python)

1) Crea package interfacce (se non esiste gia):
ros2 pkg create my_robot_interfaces --build-type ament_cmake

in tal caso vedi se esiste

2) Crea package Python per il nodo (se non esiste gia):
ros2 pkg create task1_pkg --build-type ament_python --dependencies rclpy control_msgs trajectory_msgs my_robot_interfaces

verificare se dopo rclpy serve inserire testo

=====================================================================
FASE 2 - CONFIGURAZIONE ACTION MoveHead
=====================================================================
1) Crea cartella action nel package interfacce:
mkdir -p ~/progetto_12_ws/src/my_robot_interfaces/action

2) Crea file action:
nano ~/progetto_12_ws/src/my_robot_interfaces/action/MoveHead.action

Contenuto consigliato (coerente con Esercitazione 4):
float32 min
float32 max
float32 step
---
bool success
string message
---
float32 current_position
bool moving

3) Modifica CMakeLists.txt del package my_robot_interfaces:
File da modificare:
~/progetto_12_ws/src/my_robot_interfaces/CMakeLists.txt

Aggiunte minime:
- find_package(rosidl_default_generators REQUIRED)
- rosidl_generate_interfaces(${PROJECT_NAME}
    "action/MoveHead.action"
  )
- ament_export_dependencies(rosidl_default_runtime)

4) Modifica package.xml del package my_robot_interfaces:
File da modificare:
~/progetto_12_ws/src/my_robot_interfaces/package.xml

Aggiunte minime:
- <buildtool_depend>rosidl_default_generators</buildtool_depend>
- <exec_depend>rosidl_default_runtime</exec_depend>
- <member_of_group>rosidl_interface_packages</member_of_group>

=====================================================================
FASE 3 - INTEGRAZIONE DEL NODO 1 NEL PACKAGE PYTHON
=====================================================================
1) Copia il nodo 1 nel package Python:
cp /percorso_della_tua_SSD/Task1/det_task1.py ~/progetto_12_ws/src/task1_pkg/task1_pkg/det_task1.py
chmod +x ~/progetto_12_ws/src/task1_pkg/task1_pkg/det_task1.py

2) Modifica setup.py del package task1_pkg:
File da modificare:
~/progetto_12_ws/src/task1_pkg/setup.py

In entry_points aggiungi:
'det_task1 = task1_pkg.det_task1:main'

3) Modifica package.xml del package task1_pkg:
File da modificare:
~/progetto_12_ws/src/task1_pkg/package.xml

Verifica dipendenze presenti:
- rclpy
- control_msgs
- trajectory_msgs
- my_robot_interfaces

=====================================================================
FASE 4 - BUILD E SOURCE
=====================================================================
1) Build selettivo:
cd ~/progetto_12_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select my_robot_interfaces task1_pkg facciamo di tutto semo pazzi

2) Source workspace: 
source ~/progetto_12_ws/install/setup.bash

=====================================================================
FASE 5 - RUN (GAZEBO + NODO 1)
=====================================================================
Terminale A - Avvia Gazebo TIAGo:
source /opt/ros/humble/setup.bash
source ~/progetto_12_ws/install/setup.bash
ros2 launch tiago_gazebo tiago_gazebo.launch.py is_public_sim:=True

Terminale B - (Opzionale ma utile) Porta il robot in postura comoda:
source /opt/ros/humble/setup.bash
source ~/progetto_12_ws/install/setup.bash
ros2 run play_motion2 run_motion unfold_arm

Terminale C - Avvia Nodo 1 (server custom MoveHead):
source /opt/ros/humble/setup.bash
source ~/progetto_12_ws/install/setup.bash
ros2 run task1_pkg det_task1

Terminale D - Invia goal per far partire scansione testa:
source /opt/ros/humble/setup.bash
source ~/progetto_12_ws/install/setup.bash
ros2 action send_goal /move_head my_robot_interfaces/action/MoveHead "{min: -0.6, max: 0.6, step: 0.2}" --feedback

=====================================================================
FASE 6 - VERIFICA COERENZA CON TASK 1 (PARTE NODO 1)
=====================================================================
Checklist rapida:
1) L action /move_head esiste:
ros2 action list -t

2) Il nodo accetta il goal:
- output terminale C: "Goal ricevuto!"
- output terminale D: goal accepted

3) Feedback in esecuzione presente:
- output terminale D con current_position che varia nel range richiesto

4) Movimento testa coerente:
- in Gazebo head_1_joint ruota sinistra/destra
- head_2_joint resta circa fisso a -0.57

5) Nessun errore bloccante:
- niente eccezioni Python nel terminale C
- niente "action server non disponibile" persistente

=====================================================================
NOTE OPERATIVE IMPORTANTI
=====================================================================
1) Con il file det_task1.py la scansione NON parte da sola: parte solo dopo invio goal su /move_head.
2) Se vuoi scansione autonoma senza client, il nodo 1 va convertito in ActionClient+timer (come alternativa).
3) Nodo 2 (ArUco detection + TF) verra integrato dopo, poi si costruira il launch unico.
