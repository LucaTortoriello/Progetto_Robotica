SETUP INIZIALE - CONFIGURAZIONE setup.py (IMPORTANTE!)
=======================================================
COSA È IL setup.py?
Il setup.py è il file di configurazione del pacchetto ROS2.
Dice al sistema quali nodi sono disponibili nel pacchetto e come lanciarli con ros2 run.

QUANDO configurarlo?
PRIMA di eseguire colcon build. Questo è IL PRIMO STEP prima di tutto il resto.

PERCHE' è necessario?
Senza la configurazione nel setup.py, ROS2 non sa come eseguire i vostri nodi.
Se non aggiungete gli entry point, riceverete errore: "Could not find executable..."

COME CONFIGURARE IL setup.py - STEP BY STEP
=============================================
□ Aprire il file setup.py del pacchetto progetto_robotica:
  cat ~/progetto_n_ws/src/progetto_robotica/setup.py

  OPPURE aprire in un editor:
  nano ~/progetto_n_ws/src/progetto_robotica/setup.py

□ Localizzare la sezione 'entry_points' (solitamente verso la fine del file)
  Dovrebbe assomigliare a:
  
  entry_points={
      'console_scripts': [
          'det_task1 = progetto_robotica.det_task1:main',
      ],
  }

□ Verificare che 'det_task1' sia già presente (dal nodo 1)

□ AGGIUNGERE il nuovo entry point per il nodo 2 (aruco_detector_all_markers)
  Modificare la sezione 'console_scripts' per includerlo:
  
  entry_points={
      'console_scripts': [
          'det_task1 = progetto_robotica.det_task1:main',
          'aruco_detector_all_markers = progetto_robotica.aruco_detector_all_markers:main',
      ],
  }

□ Spiegazione della sintassi:
  'aruco_detector_all_markers' = nome del comando da usare in terminale (ros2 run <pkg> aruco_detector_all_markers)
  'progetto_robotica' = nome del pacchetto
  'aruco_detector_all_markers' = nome del file Python (senza .py)
  'main' = nome della funzione principale nel file

□ Salvare il file:
  Se usate nano: Ctrl+O, Invio, Ctrl+X

□ Verificare che il file sia stato salvato correttamente:
  cat ~/progetto_n_ws/src/progetto_robotica/setup.py | grep -A 5 entry_points

□ Dovrebbe mostrare ENTRAMBI gli entry point:
  'det_task1 = progetto_robotica.det_task1:main'
  'aruco_detector_all_markers = progetto_robotica.aruco_detector_all_markers:main'

NOTE IMPORTANTI
===============
- I topic /aruco_camera_* e /aruco_base_* vengono creati DINAMICAMENTE
  quando il primo marker con quell'ID viene rilevato
  
- Se non vengono rilevati marker, nessun topic viene creato
  (verificare che i marker ArUco siano presenti nella scena Gazebo)

- Le coordinate base_frame dipendono dalla trasformazione TF camera->base
  Se questa non è disponibile, solo le pose camera_frame saranno pubblicate

- Il timer di republish (100ms) mantiene costanti le pose anche se il robot
  smette di vedere momentaneamente i marker

- Per debug: usare "ros2 node list" per verificare che i tre nodi siano attivi
