1. INTRODUZIONE AI SERVICES
================================================================================

I Service sono uno dei meccanismi di comunicazione principali in ROS 2. A 
differenza dei Topic (comunicazione asimmetrica publish/subscribe), i Service 
implementano un modello di comunicazione SINCRONO (Richiesta/Risposta).

Un Service consente a un nodo client di inviare una richiesta a un nodo server 
e aspettare una risposta specifica prima di continuare l'esecuzione.

2. ARCHITETTURA CLIENT-SERVER
================================================================================

2.1 Server
   - Riceve una richiesta da un client
   - Elabora la richiesta
   - Invia una risposta
   - Rimane in attesa di nuove richieste
   - Può servire più client in sequenza

2.2 Client
   - Invia una richiesta al server
   - Attende la risposta (blocca l'esecuzione)
   - Riceve i dati di risposta
   - Continua l'esecuzione dopo la risposta
   - Può aspettare con timeout

2.3 Definizione Interface
   - Request: struttura dati della richiesta
   - Response: struttura dati della risposta
   - Definite in file .srv (Service Definition)


3. CREAZIONE DI UN SERVICE (.srv)
================================================================================

Un file .srv definisce la struttura della richiesta e della risposta.
Formato: <nome_package>/srv/<nome_service>.srv

Sintassi:
---
<tipo_dato> <nome_campo>  # Request
---
<tipo_dato> <nome_campo>  # Response
---

4. CREAZIONE DI UN SERVER IN PYTHON
================================================================================

4.1 Struttura generale:

import rclpy
from rclpy.node import Node
from my_package.srv import MyService  # Import del service

class MyServiceServer(Node):
    def __init__(self):
        super().__init__('my_service_server')
        # Creazione del service
        self.srv = self.create_service(
            MyService,                          # Tipo di service
            'my_service',                       # Nome del service
            self.service_callback               # Callback function
        )
        self.get_logger().info('Server pronto: my_service')

    def service_callback(self, request, response):
        # Elaborazione della richiesta
        self.get_logger().info(f'Richiesta ricevuta: {request}')
        
        # Logica del service
        response.result = request.input * 2
        response.success = True
        
        return response

def main(args=None):
    rclpy.init(args=args)
    server = MyServiceServer()
    rclpy.spin(server)
    rclpy.shutdown()

if __name__ == '__main__':
    main()

5. CREAZIONE DI UN CLIENT IN PYTHON
================================================================================

5.1 Struttura generale:

import rclpy
from rclpy.node import Node
from my_package.srv import MyService

class MyServiceClient(Node):
    def __init__(self):
        super().__init__('my_service_client')
        # Creazione del client
        self.client = self.create_client(
            MyService,
            'my_service'
        )
        
        # Attesa che il servizio sia disponibile
        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Servizio non disponibile, attendo...')
        
        self.get_logger().info('Servizio disponibile, invio richiesta')

    def send_request(self, value):
        request = MyService.Request()
        request.input = value
        
        # Invio asincrono della richiesta
        self.future = self.client.call_async(request)
        self.future.add_done_callback(self.response_callback)

    def response_callback(self, future):
        try:
            response = future.result()
            self.get_logger().info(f'Risposta ricevuta: {response}')
        except Exception as e:
            self.get_logger().error(f'Errore: {e}')

def main(args=None):
    rclpy.init(args=args)
    client = MyServiceClient()
    client.send_request(5)
    rclpy.spin(client)
    rclpy.shutdown()

import rclpy
from rclpy.node import Node
from my_package.srv import MyService
import time

def main(args=None):
    rclpy.init(args=args)
    node = Node('client_timeout')
    
    client = node.create_client(MyService, 'my_service')
    
    # Attesa con timeout
    if not client.wait_for_service(timeout_sec=5.0):
        node.get_logger().error('Servizio non disponibile dopo 5 secondi!')
        rclpy.shutdown()
        return
    
    request = MyService.Request()
    request.input = 20
    
    try:
        response = client.call(request)
        node.get_logger().info(f'Successo: {response.result}')
    except Exception as e:
        node.get_logger().error(f'Errore nella chiamata: {e}')
    
    rclpy.shutdown()

7. CICLO DI VITA DI UNA CHIAMATA A SERVICE
================================================================================

Sequenza temporale:

1. SERVER CREATION
   - Server registra il service con il middleware ROS 2
   - Server si mette in attesa di richieste
   - Log: "Service available"

2. CLIENT CREATION
   - Client crea il client object
   - Client cerca il service (wait_for_service)
   - Se servizio trovato, pronto per inviare richieste

3. REQUEST TRANSMISSION
   - Client prepara la richiesta con i dati
   - Client invia la richiesta al server via middleware
   - Client si blocca aspettando la risposta (o registra callback)

4. SERVER PROCESSING
   - Server riceve la richiesta
   - Callback del server viene eseguito
   - Server elabora i dati
   - Server crea la risposta

5. RESPONSE TRANSMISSION
   - Server invia la risposta al client
   - Middleware consegna la risposta

6. CLIENT RECEIVES
   - Client riceve la risposta
   - Se sincrono: continua l'esecuzione dopo il call()
   - Se asincrono: esegue il response_callback

7. CONNECTION CLEANUP
   - Se non più usato, il client può liberare risorse
   - Se server termina, nuove richieste falliscono


8. BEST PRACTICES
================================================================================

8.1 Design di Service:
- Usa service per operazioni DISCRETE (completare/fallire)
- Usa topic per STREAM di dati continui
- Mantieni request/response SEMPLICI ed ESSENZIALI
- Evita service per operazioni che richiedono UPDATE CONTINUI

8.2 Implementazione:
- SEMPRE aspetta che il servizio sia disponibile (wait_for_service)
- Implementa TIMEOUT per evitare blocchi indefiniti
- Usa try/except per gestire eccezioni
- Log appropriati per debugging
- Documenta il servizio nella docstring

8.3 Performance:
- Service sincroni possono bloccare il nodo
- Usa callback asincroni se possibile
- Evita operazioni lunghe nel callback del server
- Monitora i tempi di risposta

8.4 Sicurezza:
- Valida sempre i dati ricevuti nel server
- Implementa controlli dei parametri
- Gestisci eccezioni per evità crash
- Log di tutte le operazioni critiche

9.2 Server Implementation:

#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from my_tiago.srv import GripperControl

class GripperServer(Node):
    def __init__(self):
        super().__init__('gripper_server')
        self.srv = self.create_service(
            GripperControl,
            'gripper_control',
            self.gripper_callback
        )
        self.get_logger().info('Gripper Control Server Online')
        self.gripper_state = 'closed'

    def gripper_callback(self, request, response):
        self.get_logger().info(
            f'Comando ricevuto: open={request.open}, force={request.force}'
        )
        
        try:
            if request.open:
                # Logica per aprire il gripper
                self.gripper_state = 'open'
                response.status = 'Gripper aperto'
            else:
                # Logica per chiudere il gripper
                if request.force > 100:
                    response.status = 'Gripper chiuso con forza controllata'
                else:
                    response.status = 'Forza non valida'
                    response.success = False
                    return response
                self.gripper_state = 'closed'
            
            response.success = True
        except Exception as e:
            response.success = False
            response.status = f'Errore: {str(e)}'
            self.get_logger().error(response.status)
        
        return response

def main(args=None):
    rclpy.init(args=args)
    server = GripperServer()
    rclpy.spin(server)
    rclpy.shutdown()

if __name__ == '__main__':
    main()

9.3 Client Implementation:

#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from my_tiago.srv import GripperControl

class GripperClient(Node):
    def __init__(self):
        super().__init__('gripper_client')
        self.client = self.create_client(
            GripperControl,
            'gripper_control'
        )
        
        # Attendi disponibilità del servizio
        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Gripper service non disponibile...')

    def open_gripper(self, force=50.0):
        request = GripperControl.Request()
        request.open = True
        request.force = force
        
        self.get_logger().info(f'Apertura gripper con forza {force}...')
        response = self.client.call(request)
        
        if response.success:
            self.get_logger().info(f'✓ {response.status}')
            return True
        else:
            self.get_logger().error(f'✗ {response.status}')
            return False

    def close_gripper(self, force=75.0):
        request = GripperControl.Request()
        request.open = False
        request.force = force
        
        self.get_logger().info(f'Chiusura gripper con forza {force}...')
        response = self.client.call(request)
        
        if response.success:
            self.get_logger().info(f'✓ {response.status}')
            return True
        else:
            self.get_logger().error(f'✗ {response.status}')
            return False

def main(args=None):
    rclpy.init(args=args)
    client = GripperClient()
    
    # Esecuzione comandi
    client.open_gripper(force=60.0)
    client.close_gripper(force=80.0)
    
    rclpy.shutdown()

if __name__ == '__main__':
    main()


10. TROUBLESHOOTING
================================================================================

Problema: "Service not available"
Soluzione:
- Verificare che il server sia in esecuzione (ros2 node list)
- Controllare il nome del service (ros2 service list)
- Aumentare il timeout in wait_for_service
- Verificare il namespace del service

Problema: "Timeout nella risposta"
Soluzione:
- Il server è troppo lento
- Aumentare il timeout
- Debuggare la logica del server
- Verificare se il server è bloccato

Problema: "Tipi di dato non corrispondono"
Soluzione:
- Rigenerare i package Python dopo modifica .srv
- Importare il tipo corretto nel client/server
- Verificare la versione dei package

Problema: "Client non riceve la risposta"
Soluzione:
- Verificare che la risposta sia completamente inizializzata
- Controllare che il server ritorna effettivamente la risposta
- Verificare la connettività di rete (per sistemi distribuiti)

12.3 Server Implementation - head_service_server.py:

#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from example_interfaces.srv import SetBool
from trajectory_msgs.msg import JointTrajectory, JointTrajectoryPoint
from rclpy.publisher import Publisher
import time

class HeadMotionServer(Node):
    def __init__(self):
        super().__init__('head_motion_server')
        
        # Service
        self.srv = self.create_service(
            SetBool,
            'play_motion_service',
            self.head_motion_callback
        )
        
        # Publisher per il comando della testa
        self.head_pub: Publisher = self.create_publisher(
            JointTrajectory,
            '/head_controller/joint_trajectory',
            10
        )
        
        self.get_logger().info('Head Motion Service Server avviato')
        self.head_position = 'neutral'

    def head_motion_callback(self, request, response):
        """
        Callback per il service SetBool.
        - request.data = True: muovi la testa
        - request.data = False: testa neutra
        """
        self.get_logger().info(f'Comando ricevuto: move={request.data}')
        
        try:
            if request.data:
                # Muovi la testa
                self.move_head_down()
                response.success = True
                response.message = "Testa mossa verso il basso"
                self.head_position = 'down'
            else:
                # Testa in posizione neutra
                self.move_head_neutral()
                response.success = True
                response.message = "Testa in posizione neutra"
                self.head_position = 'neutral'
                
        except Exception as e:
            response.success = False
            response.message = f"Errore nel movimento: {str(e)}"
            self.get_logger().error(response.message)
        
        return response

    def move_head_down(self):
        """Muove la testa verso il basso"""
        trajectory = JointTrajectory()
        trajectory.joint_names = ['head_1_joint', 'head_2_joint']
        
        point = JointTrajectoryPoint()
        point.positions = [6.67e-07, -0.86]  # Posizione bassa
        point.time_from_start.sec = 2
        
        trajectory.points.append(point)
        
        self.get_logger().info('Movimento testa: DOWN')
        self.head_pub.publish(trajectory)

    def move_head_neutral(self):
        """Muove la testa in posizione neutra"""
        trajectory = JointTrajectory()
        trajectory.joint_names = ['head_1_joint', 'head_2_joint']
        
        point = JointTrajectoryPoint()
        point.positions = [0.0, 0.0]  # Posizione neutra
        point.time_from_start.sec = 1
        
        trajectory.points.append(point)
        
        self.get_logger().info('Movimento testa: NEUTRAL')
        self.head_pub.publish(trajectory)

def main(args=None):
    rclpy.init(args=args)
    server = HeadMotionServer()
    
    try:
        rclpy.spin(server)
    except KeyboardInterrupt:
        server.get_logger().info('Server terminato dall\'utente')
    
    rclpy.shutdown()

if __name__ == '__main__':
    main()


12.4 Client Implementation - head_service_client.py:

#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from example_interfaces.srv import SetBool
import sys

class HeadMotionClient(Node):
    def __init__(self):
        super().__init__('head_motion_client')
        self.client = self.create_client(
            SetBool,
            'play_motion_service'
        )
        
        # Attesa che il servizio sia disponibile
        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Service non disponibile, attendo...')

    def send_command(self, move: bool):
        """Invia comando di movimento della testa"""
        request = SetBool.Request()
        request.data = move
        
        action = "muovi la testa" if move else "testa neutra"
        self.get_logger().info(f'Invio comando: {action}')
        
        response = self.client.call(request)
        
        self.get_logger().info(f'Risposta: {response.message}')
        return response.success

def main(args=None):
    rclpy.init(args=args)
    client = HeadMotionClient()
    
    # Esempio: muovi la testa
    print("\n=== MOVIMENTO TESTA DOWN ===")
    client.send_command(True)
    
    # Attendi un po'
    import time
    time.sleep(3)
    
    # Riporta allo stato neutro
    print("\n=== RESTITUISCI TESTA A NEUTRO ===")
    client.send_command(False)
    
    rclpy.shutdown()

if __name__ == '__main__':
    main()

12.6 Interfaccia SetBool:

La interfaccia SetBool è una interfaccia standard di ROS 2 (example_interfaces).

Definizione:
---
bool data
---
bool success
string message
---

Uso:
- Request: SetBool.Request() con request.data (True/False)
- Response: response.success (successo operazione) + response.message (messaggio descrittivo)
